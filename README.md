# Control de Clases · Escuela Dominical

Formulario para que los maestros de la Escuela Dominical envíen sus clases con antelación para revisión pastoral.

- Dirección: https://clases.pastorea.me
- La página es estática (`index.html`). Los envíos van al servicio de Google Apps Script «Control de Clases», que guarda los datos en una hoja de cálculo y los archivos en Google Drive.
- Para probar la página sin enviar nada, añada `?demo` a la dirección.
